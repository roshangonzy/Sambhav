ICSE Mathematics Practice

Practice Paper 1 Module 1: Factorisation

Prepared for: Sambhav | Grade 10

5-Day Study Plan • 12 Questions / Day

Day 1: Remainder Theorem

Fundamental Concepts

1 Mark Questions

  1. Find the remainder when $2x^2 - 5x + 1$ is divided by $x - 2$.
  2. Find the remainder when $3x^3 - 7x^2 + 4x - 1$ is divided by $x - 1$.
  3. Find the remainder when $x^3 + 4x^2 - 3x + 10$ is divided by $x + 4$.
  4. Find the remainder when $x^4 - 3x^2 + 5x - 6$ is divided by $x + 2$.
  5. Without actual division, find the remainder when $x^3 - 2x^2 + 5x - 7$ is divided by $x - 3$.

2 Marks Questions

  1. Find the remainder (without division) on dividing $3x^2 + 5x - 9$ by $3x - 2$.
  2. Find $k$ if the division of $x^3 + 2x^2 - kx + 10$ by $x - 2$ leaves a remainder of $0$.
  3. Find the value of $a$ if the division of $ax^3 + 9x^2 + 4x - 10$ by $x + 3$ leaves a remainder of $5$.
  4. Find the remainder when $2x^3 - 3x^2 + 4x + 7$ is divided by $2x + 1$.

3 Marks Questions

  1. The polynomials $ax^3 + 3x^2 - 3$ and $2x^3 - 5x + a$, when divided by $x - 4$, leave the same remainder. Find the value of $a$.
  2. Find the value of $m$, if $mx^3 + 2x^2 - 3$ and $x^2 - mx + 4$ leave the same remainder when divided by $x - 2$.

4 Marks Question

  1. When $x^3 + 2x^2 - kx + 4$ is divided by $x - 2$, the remainder is $k$. Find the value of the constant $k$. With this value of $k$, find the remainder when the polynomial is divided by $x + 1$.

Day 2: Factor Theorem

Fundamental Concepts

1 Mark Questions

  1. Use the factor theorem to determine whether $x - 1$ is a factor of $x^3 - x^2 + x - 1$.
  2. Determine if $x + 2$ is a factor of $x^3 + 3x^2 + 3x + 1$.
  3. Show that $x - 3$ is a factor of $x^2 - 5x + 6$.
  4. If $f(x) = x^2 - 7x + 10$, evaluate $f(2)$ to check if $x - 2$ is a factor.
  5. Check if $2x - 1$ is a factor of $2x^3 - x^2$.

2 Marks Questions

  1. Use the factor theorem to show that $x - 2$ is a factor of $x^3 + x^2 - 4x - 4$.
  2. Show that $2x + 3$ is a factor of $2x^3 + x^2 - 7x - 6$.
  3. Find the value of $k$ if $x - 3$ is a factor of $x^3 - kx^2 + 2x - 3$.
  4. Find the value of $a$ if $x + 2$ is a factor of $4x^3 - 13x + a$.

3 Marks Questions

  1. If $x - 2$ and $x + 3$ are factors of $x^3 + ax^2 + bx - 30$, find the values of $a$ and $b$.
  2. Given that $x - 1$ and $x + 2$ are factors of the polynomial $x^3 + ax^2 - bx - 6$, find $a$ and $b$.

4 Marks Question

  1. Find the values of $a$ and $b$ so that the polynomial $x^3 + ax^2 + bx - 6$ is completely divisible by $x^2 - 4x + 3$. (Hint: factorise the divisor first).

Day 3: Factorising Completely

Fundamental Concepts

1 Mark Questions

  1. By trial, find one integral root for $x^3 - 2x^2 - x + 2 = 0$.
  2. For $f(x) = x^3 - 7x + 6$, calculate $f(1)$.
  3. Calculate $f(-1)$ for the polynomial $x^3 + 6x^2 + 11x + 6$.
  4. Find the value of $x^3 - 3x^2 - 9x - 5$ at $x = -1$.
  5. Calculate $f(2)$ for $x^3 - 4x^2 + x + 6$.

2 Marks Questions

  1. Divide $x^3 - 2x^2 - x + 2$ by $x - 1$.
  2. Divide $x^3 - 6x^2 + 11x - 6$ by $x - 2$.
  3. Factorise the quadratic expression: $x^2 - x - 2$.
  4. Factorise the quadratic expression: $x^2 - 4x + 3$.

3 Marks Questions

  1. Given that $x - 2$ is a factor of $2x^3 - 7x^2 + 7x - 2$, factorise the given expression completely.
  2. Given that $x + 2$ is a factor of $x^3 + x^2 - 4x - 4$, factorise the polynomial completely.

4 Marks Question

  1. Using the Remainder and Factor Theorem, factorise the following polynomial completely: $x^3 + 10x^2 - 37x + 26$.

Day 4: "Added/Subtracted" & Tricky Phrasing

Advanced Applications

1 Mark Questions

  1. If $x - 2$ is a factor of $x^3 - ax^2 + bx - 4$, what does $f(2)$ equal?
  2. Let $f(x) = 2x^3 - 5x^2 + 4x + 1$. Find $f(1)$.
  3. Find the first integral factor of $x^3 - 19x - 30$ by trial.
  4. State the degree of the polynomial $4x^3 - 3x^2 + 2x - 1$.
  5. Factorise: $x^2 - 16$.

2 Marks Questions

  1. What must be subtracted from $16x^3 - 8x^2 + 4x + 7$ so that the resulting expression has $2x + 1$ as a factor?
  2. What number must be added to $x^3 - 3x^2 - 12x + 19$ so that the polynomial is exactly divisible by $x - 2$?
  3. Find $a$ if $x - 2$ is a factor of $x^3 - 2x^2 + ax - 4$.
  4. Factorise completely: $x^3 - x^2 - 10x - 8$ if $x + 1$ is a given factor.

3 Marks Questions

  1. The expression $2x^3 + ax^2 + bx - 2$ leaves a remainder of $7$ and $0$ when divided by $2x - 3$ and $x + 2$ respectively. Calculate the values of $a$ and $b$.
  2. Find the values of $a$ and $b$ so that the polynomial $x^3 - ax^2 - 13x + b$ has $(x-1)$ and $(x+3)$ as factors.

4 Marks Question

  1. Using the Factor Theorem, factorise the polynomial $3x^3 + 2x^2 - 19x + 6$ completely.

Day 5: Past ICSE Board Questions

Review & Exam Preparation

1 Mark Questions

  1. Calculate the remainder when $2x^3 - x^2 + 3x - 5$ is divided by $x$.
  2. Evaluate $f(-1)$ for $f(x) = 3x^3 + 8x^2 - 6x + 1$.
  3. Does the polynomial $x^3 + 2x^2 - 5x - 6$ leave a remainder of $0$ when divided by $x + 1$?
  4. Write the fully factorised form of $x^3 - 4x$.
  5. By trial, check if $x = 2$ is a root of $2x^3 - 7x^2 + 2x + 3 = 0$.

2 Marks Questions

  1. If $x - 2$ is a factor of $2x^3 - x^2 - px - 2$, find $p$.
  2. When $x^3 + 3x^2 - mx + 4$ is divided by $x - 2$, the remainder is $m + 3$. Find $m$.
  3. Show that $2x + 1$ is a factor of $4x^3 + 12x^2 + 7x + 1$.
  4. If $x + 1$ is a factor of $ax^3 + x^2 - 2x + 4a - 9$, find $a$.

3 Marks Questions

  1. The polynomials $ax^3 + 3x^2 - 13$ and $2x^3 - 5x + a$ leave the same remainder when divided by $x - 2$. Find the value of $a$.
  2. Find $a$ and $b$ if $x - 1$ and $x - 2$ are factors of $x^3 - ax + b$.

4 Marks Question

  1. If $(x - 2)$ is a factor of the expression $2x^3 + ax^2 + bx - 14$ and when the expression is divided by $(x - 3)$, it leaves a remainder of $52$. Find the values of $a$ and $b$. Hence, factorise the expression completely.
